# Hướng dẫn merge request

1. Tạo nhánh `feature/<tên>` từ `origin/dev`, commit, push.
2. Tạo merge request lần lượt: `feature/<tên>` → `dev` → `stg` → `main`.
3. Mỗi merge request: chờ tôi approve.
4. Trước khi merge, xem GitHub Action:
   - Các check (vd. `neon`, `SonarCloud`) phải `SUCCESS`.
   - Log `terraform plan`: chỉ có `to add` như mong đợi, `0 to destroy`.
5. Merge bằng `gh pr merge <số> --merge`.
6. Sau khi merge vào `main`, xem workflow `terraform-*` chạy apply: `Apply complete!`.
